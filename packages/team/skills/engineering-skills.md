# Engineering Skills (vendored)

Every team member's init prompt is appended with an **Engineering Skills** section
(generated by `src/agent-skills.js`). That section lists 20 skills vendored from
[`addyosmani/agent-skills`](https://github.com/addyosmani/agent-skills) (MIT),
grouped into six phases, plus a role-aware shortlist.

The skill spec files live in this repo at `skills/engineering/<name>/SKILL.md`
so agents `Read` them locally — no runtime network dependency. See
`skills/engineering/UPSTREAM.md` for the pinned commit SHA and sync procedure.

## The six phases (→ slash commands when the plugin is installed)

| Phase  | Command         | Purpose                                     |
|--------|-----------------|---------------------------------------------|
| define | `/spec`         | Clarify what to build                        |
| plan   | `/plan`         | Break into verifiable atomic tasks           |
| build  | `/build`        | Write code incrementally                     |
| verify | `/test`         | Prove functionality via tests & debugging    |
| review | `/review`       | Quality, simplification, security, perf gates|
| ship   | `/ship`         | Version, deploy, document, migrate           |

Also available: `/code-simplify` for the `code-simplification` skill specifically
(an extra, non-phase command).

## Catalog (20 skills)

- **define**: `idea-refine`, `spec-driven-development`
- **plan**: `planning-and-task-breakdown`
- **build**: `incremental-implementation`, `test-driven-development`,
  `context-engineering`, `source-driven-development`, `frontend-ui-engineering`,
  `api-and-interface-design`
- **verify**: `browser-testing-with-devtools`, `debugging-and-error-recovery`
- **review**: `code-review-and-quality`, `code-simplification`,
  `security-and-hardening`, `performance-optimization`
- **ship**: `git-workflow-and-versioning`, `ci-cd-and-automation`,
  `deprecation-and-migration`, `documentation-and-adrs`, `shipping-and-launch`

## How to invoke a skill

### Option A — plugin installed (preferred)
```
/plugin marketplace add addyosmani/agent-skills
/plugin install agent-skills@addy-agent-skills
```
Then invoke the matching slash command (`/spec`, `/plan`, `/build`, `/test`,
`/review`, `/code-simplify`, `/ship`). The plugin wires the right skills
automatically.

### Option B — Read the vendored spec (no plugin, default)
Every agent's init prompt contains the absolute path to the vendor directory.
Use `Read` on:
```
<vendor-dir>/<skill-name>/SKILL.md
```
The concrete path is injected into your prompt at launch time. Follow the
Process, Red Flags, and Verification sections of the file you read.

## Role-aware recommendations

`buildSkillsSection(role)` looks at each agent's role and surfaces a shortlist:

- **coordinator / team-lead** → define + plan + review + ship
- **researcher / investigator** → define + build (spec-driven, source-driven) + verify
- **implementer / engineer** → plan + build + verify
- **reviewer** → review (code quality, simplify, security, perf)
- **tester / QA** → verify + review
- **shipper / devops / SRE** → ship + review

Fallback bucket is `generalist`: plan + build + verify + review.
